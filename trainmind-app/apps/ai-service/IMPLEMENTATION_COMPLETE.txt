================================================================================
API ENDPOINTS
================================================================================

GENERATION ENDPOINTS:
  POST /ai/generate
    - Input: prompt, athlete_id?, context_type, namespace, top_k
    - Output: content, sources[], structured_data?
    - Purpose: Context-aware content generation

  POST /ai/coach
    - Input: question, athlete_id?, category?, namespaces[], top_k
    - Output: answer, sources[], references[]
    - Purpose: Expert coaching consultation

EMBEDDING ENDPOINTS:
  POST /ai/embed
    - Input: texts[], namespace, metadata[]
    - Output: count, namespace, details?
    - Purpose: Create embeddings and store in Pinecone

  GET /ai/embed/stats
    - Output: Index statistics with namespace breakdown
    - Purpose: Monitor vector database

CHAT ENDPOINTS:
  POST /ai/chat
    - Input: messages[], athlete_id?, stream, temperature, max_tokens
    - Output: content, sources[], finish_reason (or SSE stream)
    - Purpose: RAG-enhanced conversation

HEALTH ENDPOINTS:
  GET /health
    - Output: status, version, services{}
    - Purpose: Service health verification

  GET /
    - Output: Service info and endpoint list
    - Purpose: Service root information

QUICK START
================================================================================

1. CONFIGURATION
   cd apps/ai-service
   cp .env.example .env
   # Edit .env with your API keys

2. LOCAL DEVELOPMENT
   python -m venv venv
   source venv/bin/activate  # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   uvicorn app.main:app --reload --port 3002

3. DOCKER DEPLOYMENT
   cd ../..
   docker-compose up -d ai-service

4. VERIFY
   curl http://localhost:3002/health

5. ACCESS DOCS
   http://localhost:3002/docs (Swagger UI)
   http://localhost:3002/redoc (ReDoc)
