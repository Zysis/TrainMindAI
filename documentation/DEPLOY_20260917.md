## 4. What is already in the database

```bash
dc exec -T postgres psql -U trainmind -d trainmind_db <<'SQL'
SELECT to_regclass('public.refresh_tokens') AS refresh_tokens,
       to_regclass('public.staff_invites')  AS staff_invites,
       EXISTS (SELECT 1 FROM pg_enum e JOIN pg_type t ON t.oid = e.enumtypid
               WHERE t.typname = 'ReportAudience' AND e.enumlabel = 'MANAGEMENT') AS management;
SELECT migration_name FROM _prisma_migrations ORDER BY migration_name DESC LIMIT 6;
SQL
```

Note which of the three is empty / `f`: those migrations get applied at step 6.

