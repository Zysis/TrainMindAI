# Workload Management nel Basket

## Principi fondamentali

Il workload management è il processo sistematico di pianificazione, monitoraggio e regolazione del carico di lavoro degli atleti per:
1. **Massimizzare l'adattamento** fisico e prestativo
2. **Minimizzare il rischio** di infortuni e sovrallenamento
3. **Ottimizzare il recupero** tra le sessioni
4. **Individualizzare** il carico in base allo stato dell'atleta

## Componenti del carico

### Carico esterno (External Load)
Ciò che l'atleta **fa** oggettivamente:
- Distanza percorsa (km)
- Velocità massima e media
- Numero di accelerazioni/decelerazioni
- Numero di salti
- PlayerLoad (se disponibile accelerometro)
- Tempo di gioco effettivo
- Numero di esercizi/ripetizioni

### Carico interno (Internal Load)
Come l'atleta **risponde** fisiologicamente e percettivamente:
- sRPE (session-RPE × durata)
- Frequenza cardiaca media e massima
- Tempo in zone HR
- TRIMP (Training Impulse)
- Percezione soggettiva (fatica, dolore, sonno)

## Indici di monitoraggio

### 1. Carico giornaliero
```
Carico giornaliero = sRPE della sessione
```
Se ci sono più sessioni nello stesso giorno: sommare le sRPE.

### 2. Carico settimanale
```
Carico settimanale = Σ sRPE (lunedì → domenica)
```
Range tipico basket professionistico: 1.500 – 4.000 AU/settimana.

### 3. Acute Load (Carico Acuto)
```
Acute Load = Σ sRPE (ultimi 7 giorni rolling)
```

### 4. Chronic Load (Carico Cronico)
```
Chronic Load = Media settimanale sRPE (ultimi 28 giorni rolling)
```

### 5. ACWR (Acute:Chronic Workload Ratio)
```
ACWR = Acute Load / Chronic Load
```
Target: mantenere tra 0.8 e 1.3.

### 6. Monotonia
```
Monotonia = Media giornaliera / Deviazione standard giornaliera
```
Soglia di attenzione: > 2.0.

### 7. Strain
```
Strain = Carico settimanale × Monotonia
```
Strain elevato + monotonia elevata = massimo rischio.

## Strategia di progressione del carico

### Regola del 10%
Il carico settimanale non dovrebbe aumentare più del 10% rispetto alla settimana precedente. Nel basket questa regola va adattata:
- Pre-season: incrementi fino al 15-20% accettabili se ben pianificati
- In-season: variazioni legate al calendario partite
- Post-infortunio: progressione controllata con ACWR monitoring

### Gestione del microciclo tipo (in-season)

| Giorno | Tipo | Carico atteso |
|--------|------|---------------|
| Lunedì | Recupero post-partita | Basso (RPE 2-3) |
| Martedì | Preparazione fisica + tecnica | Medio-alto (RPE 5-7) |
| Mercoledì | Tattica intensa | Alto (RPE 6-8) |
| Giovedì | Tecnica + pre-partita | Medio (RPE 4-5) |
| Venerdì | Shoot-around + riposo | Basso (RPE 1-3) |
| Sabato | **PARTITA** | Alto (RPE 7-9) |
| Domenica | Riposo o recupero | Minimo (RPE 0-2) |

## Indicatori di allarme

### Red flags (intervento immediato)
- ACWR > 1.5 per 3+ giorni consecutivi
- Monotonia > 2.0 per una settimana intera
- RPE soggettiva molto più alta dell'atteso per la sessione
- Dolore muscolare percepito ≥ 7/10
- Qualità sonno ≤ 3/10 per 3+ notti
- Calo readiness > 30% rispetto alla media individuale

### Yellow flags (monitoraggio rafforzato)
- ACWR tra 1.3 e 1.5
- Aumento monotonia sopra 1.5
- RPE soggettiva 1-2 punti sopra l'atteso
- Assenze non programmate
- Storico infortuni recente nella stessa area muscolare

## Gestione post-partita

### Giorno +1 (il giorno dopo la partita)
- Recupero attivo o riposo completo (in base al minutaggio)
- Crioterapia, foam rolling, stretching
- Monitoraggio wellness (sonno, dolori, fatica)

### Giorno +2
- Allenamento leggero (tecnica, tiro)
- Se minutaggio > 30 min: carico ridotto
- Se minutaggio < 15 min: carico normale possibile

## Specificità del basket

1. **Alta variabilità intra-settimanale**: il calendario partite (1-3 partite/settimana) crea picchi e valli naturali
2. **Componente salti**: il basket ha alta componente eccentrica (atterraggi) che va monitorata separatamente
3. **Differenze per ruolo**: center (più contatto, meno corsa), guardie (più corsa, meno contatto)
4. **Minutaggio partita variabile**: la distribuzione dei minuti influenza il carico individuale
5. **Back-to-back games**: richiedono gestione speciale del recupero
